# Changelog

## [1.0.0] - 2026-11-24
### Initial Public Release
- **Studio Obsidian UI:** Frameless desktop title bar, responsive Mobile/Desktop/TV layouts, custom skins, dynamic album-art accents, and custom wallpapers.
- **Offline-First Audio Engine:** Local SQLite library (`drift`), gapless queues, crossfade, speed/pitch controls, silence skipping, sleep timer, 5-band Android EQ, and offline track/artwork/lyrics caching.
- **Discovery & Media:** Keyless live charts, full-track search & resolver, universal playlist link importer, 30,000+ live radio stations, and RSS podcasts with offline episode downloads.
- **Synced Lyrics & Visuals:** Offline-cached `.lrc` karaoke lyrics with tap-to-seek and live Now Playing audio visualizer.
- **AteX Rewind & Tools:** Local listening analytics, daily streaks, 9:16 shareable song & stat cards, folder browser, duplicate cleaner, M3U/JSON playlist backup, desktop keyboard shortcuts, and automatic GitHub release update checker.
- **Multi-Platform Builds:** Automated GitHub Releases for Android/TV APKs, Windows Installer (`.exe`) & Portable `.zip`, macOS `.zip`, and unsigned iOS `.ipa`.
