## Features

### Playback & Audio Engine
* **True Offline-First Library:** Local SQLite indexing for `.mp3`, `.flac`, `.wav`, `.m4a`, `.aac`, and `.ogg` files plus one-tap offline downloads of audio, artwork, and synced lyrics.
* **Pro Controls:** Gapless queue playback, crossfade, silence skipping, speed (`0.5x–2.0x`), pitch (`0.5x–1.5x`), sleep timer with 10-second fade-out, and automatic pause on headphone/Bluetooth disconnect.
* **5-Band Equalizer & Bass Boost:** Native Android DSP equalizer and loudness enhancer built right into the player.
* **Audio Inspector & Tag Editor:** View file codec, bitrate, sample rate, size, and edit track Title, Artist, and Album metadata directly inside the app.

### Discovery, Radio & Podcasts
* **Live Charts & Keyless Search:** Trending India & Global charts plus instant catalog search—zero API keys or logins required.
* **Universal Playlist Importer:** Paste any public Spotify, YouTube Music, or Amazon Music playlist link to preview and import tracks locally.
* **30,000+ Live Radio Stations:** Stream Global, India, Lo-Fi, Chill, and Electronic radio stations and save favorites locally.
* **Podcasts with Offline Episodes:** Search podcasts, browse full RSS episode feeds, stream, or download episodes for offline listening.

### Visuals, Lyrics & Analytics
* **Studio Obsidian UI & Custom Skins:** Switch between *Studio Obsidian*, *Pure AMOLED*, *Midnight Cobalt*, *Crimson Vinyl*, *Emerald Studio*, dynamic album-art accents, or your own custom blurred wallpaper.
* **Live Time-Synced Karaoke Lyrics:** Automatic `.lrc` lyrics cached locally for offline playback, with auto-scroll and tap-any-line to seek.
* **Live Audio Visualizer:** Toggle between high-res album art, synced lyrics, and a reactive visualizer in Full-Screen Now Playing.
* **AteX Rewind & Share Cards:** 100% local play counts, daily streaks, top artists/tracks, weekly activity chart, and 9:16 glassmorphic song/stat cards ready to share.
* **Smart Library Management:** Auto-generated mixes (*Most Played*, *Recently Added*, *Forgotten Gems*), Folder Browser, Duplicate Cleaner, `.m3u/.m3u8` & `.json` playlist backup, and an automatic **In-App Update Checker**.

## Install Guides

<details>
<summary><strong>Android & Android TV / Fire TV</strong></summary>

1. Download `AteX_Music-Android-arm64-v8a.apk` (or `AteX_Music-Android-Universal.apk` if unsure) from [Releases](https://github.com/vaibhav1xx/AteX_Music/releases/latest).
2. Tap the APK and allow **Install from Unknown Sources** if prompted.
3. On Android TV / Fire TV, navigate smoothly using your D-pad remote.
</details>

<details>
<summary><strong>Windows PC</strong></summary>

1. Download `AteX_Music-Setup-Windows-x64.exe` (or the portable `.zip`).
2. Because this is an independent open-source app without a paid Microsoft signing certificate, Windows SmartScreen may show *"Windows protected your PC"* — click **More info → Run anyway**.
</details>

<details>
<summary><strong>iPhone & iPad (No Jailbreak Required)</strong></summary>

1. Download `AteX_Music-iOS-Unsigned.ipa` from [Releases](https://github.com/vaibhav1xx/AteX_Music/releases/latest).
2. Sideload it onto your device using **[SideStore](https://sidestore.io/)**, **[AltStore](https://altstore.io/)**, or **Sideloadly**.
</details>

<details>
<summary><strong>Android Auto, Apple CarPlay & Amazon Alexa</strong></summary>

* **Android Auto:** Open *Android Auto Settings* on your phone → tap **Version** 10 times to unlock Developer Mode → open the `⋮` menu → **Developer settings** → enable **Unknown sources**. AteX Music will appear automatically on your car dashboard.
* **Amazon Alexa & Bluetooth Speakers:** Pair your phone or PC via Bluetooth (*"Alexa, pair Bluetooth"*). Voice controls like *"Alexa, pause"*, *"Alexa, next track"*, and volume work automatically even offline.
</details>

## Keyboard Shortcuts (Desktop)

| Key | Action |
| :--- | :--- |
| `Space` | Play / Pause |
| `Ctrl + K` | Focus Search |
| `←` / `→` | Seek Backward / Forward 10s |
| `↑` / `↓` | Volume Up / Down (5%) |
| `M` | Mute / Unmute |

## Build from Source

```bash
git clone https://github.com/vaibhav1xx/AteX_Music.git
cd AteX_Music
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
```
